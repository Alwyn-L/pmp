# PMP 制造协同平台 · UI 页面清单与设计说明（V1.0）

> **设计依据**：《系统整合架构设计方案-V1.0.md》第 2 章能力分层、第 3 章实施范围、附录 A 能力拆分清单。
> **交付物**：可直接预览的全量 UI Demo（`docs/ui-demo/`）+ 本清单文档。
> **预览入口**：`docs/ui-demo/index.html`（双击即可打开；建议 1920×1080 及以上分辨率）。

## 一、交付概览

| 指标 | 数量 | 说明 |
|---|---|---|
| UI 页面 | 70 | 覆盖 9 大业务域、公共能力、运维管控、系统管理、帮助与异常 |
| 菜单分组 | 15 | 左侧导航一级分组 |
| 用户角色 | 17 | 页面级 + 按钮级 + 数据范围三层权限 |
| 架构能力 | 35 | 对应架构附录 A 能力拆分清单 |
| 能力承接方式 | 专属 27 / 借用 7 / N/A 1 | 借用与 N/A 均为间接承接，已在第六章标注边界 |
| 页面顶部操作 | 141 | 新建、审批、导出、批量处理等 |
| 行内操作 | 235 | 查看、编辑、审批、执行、回滚等 |
| 字段级说明页面 | 12 | 关键页显式定义字段规则，其余页面按列自动生成 |

页面类型分布：工作台 1 个 · 数据看板 5 个 · 列表管理 59 个 · 监控 2 个 · 搜索 1 个 · 个人中心 1 个 · 异常状态 1 个

## 二、统一视觉与交互规范

| 规范项 | 定义 |
|---|---|
| 主色 / 辅助色 | 主色 #2563eb，信息 #06b6d4，成功 #16a34a，预警 #d97706，危险 #dc2626 |
| 背景 / 面板 | 页面背景 #f4f6fb，内容面板 #ffffff，侧边栏 #0b1220 渐变 |
| 圆角 / 阴影 | 卡片圆角 10px，控件 7~8px；卡片阴影极轻，抽屉使用 40px 投影 |
| 字号 | 页面标题 21px / 卡片标题 14px / 正文 13px / 辅助说明 11~12px |
| 布局 | 左侧 248px 导航 + 60px 顶栏 + 自适应内容区，基准 1920×1080 |
| 表格 | 表头吸顶、首列强调、编码等宽字体、状态色标签、行内操作右置 |
| 看板 | KPI 卡片 + SVG 折线/柱状/环形图，无外部图表依赖 |
| 交互 | 全局搜索 Ctrl+K、角色切换即时重算权限、抽屉承载详情/表单/审批/页面说明 |
| 异常 | 403/404/500/维护/断网/空数据 六态统一文案与视觉 |

**关键操作路径标注**：每个页面标题下方提供“关键路径”快捷跳转（如 BOM → ECN → 工艺路线），点击直达目标页面；右上角“页面说明”抽屉列出完整跳转清单与业务流转规则。

## 三、角色权限模型

## 五、关键业务链路与跳转逻辑

| 链路 | 页面路径 | 说明 |
|---|---|---|
| 研发到量产 | 物料申请 → BOM 管理 → 工艺路线 → ECN 变更 → 图纸中心 → 工单管理 | 临时码转正式码，ECN 生效后同步 BOM/工艺/图纸至 ERP、MES |
| 需求到计划 | 需求预测 → S&OP 会议 → 主生产计划 → 补货计划 / 产能平衡 | 共识预测驱动主生产与补货，产能瓶颈触发外协/加班 |
| 采购到付款 | 采购申请 → 采购订单 → ASN 收货协同 → 三单匹配对账 → 发票与结算 | 订单、收货、发票三单匹配通过后进入应付 |
| 生产执行 | 工单管理 → 报工管理 → 质量管理 → 批次追溯 → 安灯异常 | 报工与完工实时回写 ERP，异常安灯升级 |
| 设备运维 | 设备管理 → 点检保养 → 故障报修 → 安灯异常 → 工单管理 | 点检逾期升级待办，故障停机计入 OEE 并联动维修备件领用 |

| 外部门户协同 | 供应商门户 / 客户门户 → 采购订单 / 销售订单 → ASN / 发货单 → 三单匹配 / 发票结算 | 外部账号由 IAM 托管并绑定编码，门户只写协同单据，业务单据仍以 ERP 为归属 |

| 退货逆向 | 退换货 RMA → 收货与上架 → 质量管理 → 应收应付 | 退货入库回补库存，不良品隔离，应收联动冲减 |

| 数据治理 | 主数据管理 → 编码规则 → 数据质量与血缘 → 指标平台 → 自助报表 | 一物一码、一源一主、单向分发、订阅消费 |

## 七、字段与权限说明的呈现方式

每个页面右上角提供 **“ⓘ 页面说明”** 抽屉，固定包含五段内容，满足“功能说明 + 字段定义 + 权限控制”要求：

1. **页面功能说明**：路由、所属模块、页面类型、功能描述、关联架构能力；
2. **字段定义说明**：字段名称、类型/规则（编码只读、枚举状态、数值千分位）、权限/来源（如“ERP 唯一写入”）；
3. **操作权限控制**：页面可见角色、按钮级允许角色、RBAC + 数据范围模型说明；
4. **跳转逻辑与数据流转**：关键跳转路由、审批流步骤、模块级数据流转规则（与架构方案的权威源约束一致）；
5. **数据展示与操作规则**：分页、筛选、状态色板、高风险操作二次确认与审计留痕要求。

| 外部账号 | 由 IAM 托管，绑定供应商编码与数据范围 | IAM 统一认证，禁止自建账号 |

### 采购订单（#/purchase-order）

| 字段 | 类型 / 规则 | 权限 / 来源 |
|---|---|---|
| 订单号 | 系统生成，PO-年份-流水 | 只读 |
| 供应商 | 必须为已准入合格供应商 | 采购员选择 |
| 价格 | 取框架协议价或询价结果，超权限需审批 | 采购员/财务 |
| 交期 | 必填，变更需供应商确认 | 采购员 |
| 状态 | 草稿/待审批/已下达/部分收货/已完成 | 流程驱动 |

### 设备管理（#/equipment）

| 字段 | 类型 / 规则 | 权限 / 来源 |
|---|---|---|
| 设备编码 | 由 MES 设备主数据生成，规则 EQ-产线-3 位流水 | MES 唯一写入，ERP 订阅 |
| 设备状态 | 运行/待机/故障/保养中/停用，采集优先、人工可修正 | 设备采集 + 生产确认 |
| 点检周期 | 按设备类型配置日/周/月计划，逾期自动升级待办 | 设备管理维护 |
| OEE | 可用率 × 性能 × 良品率，T+1 计算 | MES 采集，指标平台统一口径 |
| 维修备件 | 报修领用备件自动扣减库存并生成领料单 | WMS 实绩为准 |

### 客户门户（#/customer-portal）

| 字段 | 类型 / 规则 | 权限 / 来源 |
|---|---|---|
| 客户编码 | 门户不生成编码，注册查重通过后由 ERP 编码规则分配 | ERP 唯一写入，门户只读 |
| 可见订单 | 仅可查看绑定客户编码的订单，数据范围由 IAM 下发 | IAM 数据权限，越权返回 403 |

| 对账金额 | 以 ERP 应收为准，客户可在门户发起异议 | ERP 唯一口径 |
| 售后单 | 门户提单自动生成 RMA 草稿并进入客服受理 | 门户可写，售后系统受理 |

### API 网关管理（#/gateway）

| 字段 | 类型 / 规则 | 权限 / 来源 |
|---|---|---|
